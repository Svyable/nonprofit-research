# Security

## Scope

Report vulnerabilities in application code, CI, dependency handling, source-ingestion jobs, or any future service that could expose unpublished editorial material.

## Sensitive data boundary

The project is designed to avoid collecting sensitive incorporation materials. Do not submit passports, signatures, bank records, beneficial-owner details, tax identifiers, immigration records, or unredacted government filings through issues or pull requests.

If such material is accidentally posted, remove it from public discussion and follow GitHub's sensitive-data remediation procedures. Repository history may require additional cleanup.

## Legal-content integrity

Treat unauthorized changes to reviewed legal content, source provenance, review status, or freshness metadata as an integrity incident even when no software vulnerability is involved.
