# License matrix

The project intends to use three licenses so software, prose, and structured legal-operation data can be reused under terms appropriate to each layer:

| Material | Intended license | SPDX identifier |
| --- | --- | --- |
| Source code and executable configuration | GNU Affero General Public License v3.0 or later | `AGPL-3.0-or-later` |
| Editorial prose, guides, and reusable non-localized templates | Creative Commons Attribution 4.0 International | `CC-BY-4.0` |
| Structured jurisdiction, route, claim, source, cost, and obligation data | Open Data Commons Open Database License 1.0 | `ODbL-1.0` |

Canonical license texts are intentionally not paraphrased here. They must be vendored verbatim before the first public content release and referenced by top-level package/content notices so contributors can tell which license applies to each file.
